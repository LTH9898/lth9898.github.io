# lth9898.github.io

Personal homepage, served at https://lth9898.github.io/.

Pure static HTML/CSS/JS — no build step. Open `index.html` in a browser
(or run `python3 -m http.server`) to preview locally.

## Where to edit

- `index.html` — all content (About / News / Publications / Projects)
- `images/avatars/profile.jpg` — your profile photo
- `images/banners/banner.jpg` — background banner (referenced in `css/style.css`)
- `images/pub/` — paper / project teaser images
- `docs/bib/` — BibTeX files
- `images/logo.png` — favicon and footer logo
