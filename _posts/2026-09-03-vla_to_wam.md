<summary>Glossary</summary>

- VLA : Vision a Language Action model
  - Pre-trained VLM backbone 이 visual observation 과 language instruction을 받아서 action을 generation 함.
  - Ex) pi-0, GROOT N1
- WAM : World Action Model
  - Pre-trained World model 이나, video backbone 을 이용
  - Representation 이나 scene change 를 input, corresponding action을 찾아냄.
- World model
  - Future world state를 예측하는 모델
  - Conditioned on some action abstraction such as language, robot actions, or latent actions.
  - Future world state는 images, video, point track, obejct state, latent feature 등 다양한 것들로 표현될 수 있음.
- Grounding
  - Connecting symbols to the perceptual and motor referents that satisfy them.
  - 예를 들면, pick up the red mug  와 같은 instruction을 실제 visual perception과 motor command로 바꾸는 과정
  - Grounding gap : AI가 언어는 잘 다루지만, 그 언어를 현실에서 실제 행동으로 이어가는데 큰 차이가 있다는 것
- Inverse Dynamics
  - Given a current observation $o_t$ and a future observation $o_{t+k}$, infer the most plausible action or action sequence that would produce the transition
- Joint prediction
  - Given $o_t$ and language $l_t$, train one policy $\pi(o_t,l_t)$ to predict both future observations $o_{t+1:t+k}$ and actions $a_{t:t+k}$
  - 미래 action과 observation을 모두 같이 예측하는것
- Action chunk
  - A short horizon action sequence $a_{t:t+k}$ the k actions $a_t, a_{t+1}, \dots,a_{t_k-1}$
- Mixture of Transformers (MoT)
  - 다른 모달리티를 처리하는 transformer 들이 shared attention을 중심으로 connection 되어 있는 형태를 의미.
- Diffusion Transformer (DiT)
  - Transformer backbone을 사용하는 diffusion, flow - matching model.
  - adaptive layer-norm을 사용해서 global condtioning을 하는것으로 잘 알려져 있다.
- VAE ( Variational Auto-encoder )
  - high - resolution image를 latent로 압축하는 encoder
  - for token reducing
  - Wan 2.1’s VAE uses 4x temporal, 8x8 spatial compression
  - Wan 2.2-5B usese 4x temporal, 16 x 16 spatial compression

## Why world - Action Models?

- VLM - based VLA에 비해서 좋은 이유?

#### 1. The grounding gap

VLA는 pretraining 된 VLM 위에 action dataset으로 tuning 하는 방법으로 만들어진다. 하지만 action prediction goal 이 VLM이 원래 가지고 있었던 knowledge를 catastrophic forgetting 하게 하는 문제가 발생해서, 이를 해결하기 위해서 방안책을 고안함..  (action - learning objective diverges sharply from the original VLM objective. )

[VLM2VLA](https://arxiv.org/abs/2509.22195) frames this directly as catastrophic forgetting during the VLM-to-VLA transition.

[Knowledge Insulation](https://arxiv.org/pdf/2505.23705) : flow matching action expert의 gradient 를 VLM backbone으로 부터 분리하여 pre-trained language/vision knowledge를 유지하고, convergence를 빠르게 하며, task performance와 language following 능력을 상승시킨다.

Other recent solutions : VLM co - training, discrete action tokenizers

*이렇게 할 바에, 이미 language가 world visual change와 어떻게 mapping되는지를 알고 있는 모델을 사용하면 어떨까?*

#### 2. Core hypotheses for WAMs as policy representations

VLM backbone 대신에 pretrained video backbone을 사용하자.

Pre-trained video model들은 이미 visual scene이 어떻게 evolving 하게 되는지를 배웠기 때문에 가능하다.

Robot action을 본격적으로 보기 전에, language, visual change, plausible object interaction을 encoding 하고 있다.

1. Inverse dynamics를 예측하는것이 순수 행동 생성보다 쉬움.
   1. 순수 행동 생성 : 지시문 + 현재 관측 → 행동 을 바로 추론해야 함.
   2. 역동역학 : 현재 상태 + 원하는 미래 상태
   3. 즉, WAM이 먼저 다음에 세상이 어떻게 보일지를 상상하며, 남는 문제는 상대적으로 쉬운 역동역학 문제가 됨.
   4. pi-0.7 모델의 visual sub-goal : policy에 target image를 주면 행동 예측이 더 직접적이고 학습이 빨리 수렴하는것을 알 수 있음.
2. 비디오 사전 학습이 언어와 물리적 변화 사이의 grounding을 제공함.
   1. 비디오 생성 모델은 “텍스트 설명 → 시각적 결과”를 매핑하도록 학습
   2. Text instruction 과 physics 를 연결하는 grounding을 로봇 시연 데이터로만 배울 필요가 줄어듦.
3. 비디오 데이터가 로봇 정책을 정규화(regularize) 한다.
   1. 로봇 데이터셋은 웹 규모 비디오에 비해서 overfitting이 가능할 수 있음
   2. 로봇 fine-tuning 단계에서 action 학습만 하는것보다, world 축의 예측을 같이 진행하며, co-training 할때 성능이 가장 좋음.

#### Understanding modern WAMs : Core formulations

1. **Paradigm**
   1. what does the model predict, and how is the predicted video used to generate actions?
   2. 모델이 예측하는게 뭔가?, 그리고 video를 어떻게 prediction 하는가? 그리고 action을 generation 하는데 어떻게 쓰이는가?
2. **Action integration**
   1. how do actions actually enter the model?
   2. action이 어떤 방식으로 model에 enter 하는가?
   3. action representation이 어떤 방식으로 만들어지는가?
3. **Architecture**
   1. how are the components composed?
   2. Model architecture 가 어떤식으로 구성되는가?

### 1. Paradigm

Inverse dynamics : Predict the future, then infer the action

먼저 future를 Imagination 하고, then predict the most likely action from the video.

Video model이 이미 useful part를 배웠기 때문에, action head는 오직 inverse-dynamics에 대해서만 집중해서 학습하면 된다.

- LingBot-VA
  - Wan 2.2-5B 를 robot video-action model로 바꾼다.
  - causal. trained on long visual histories for closed loop rollouts rather than open-loop video generation
  - Mixture of Transfomer (MoT)

Joint prediction : Learn video and actions together

Action 과 future state들을 함께 예측한다.

- GR-1
  - Large-scale video 에 대해서 fine-tuned on local robot datasets with both video and action supervision.
  - Transformer policy, pretrained it on internet video prediction with readout tokens, and then fine-tuned it on robotics data with a joint video-action objective.
- DreamZero
  - Wan 2.1-I2V-14B-480p 비디오 모델로 부터 시작해서, video diffusion backbone을 joint world -action model로 만든다.
  - 하나의 DiT가 action과 video를 동시에 예측하는 구조이다.
- RoboArena Dataset
  - real world dataset. Joint prediction이 이 데이터셋에서 강점을 보임

#### Representation - only : skip video generation at inference

Video backbone을 쓰기는 하나, representation으로만 사용하고, inference 시에는 video generation을 아예 skip한다.

- Fast-WAM
  - large scale-robot pre-training을 수행하지 않음
  - 이에 더해, video generation을 test time에 skipping 하여 fast inference를 수행한다.

### 2. Action Integration

Model 안에서 action이 어떻게 represent 되는지 확인해보기

The choice is important because the pretrained backbone knows how to denoise visual tokens, not continuous robot actions, so there is a real modality mismatch.

Default action tokens

Continuous 또는 discrete action token을 input에 더하는것. 즉, 비디오와 다른 action 이라는 모달리티가 추가된 형태라고 생각하면 된다.

다만, pretrained 된 visual token이 아니기 때문에.. action representation에 adaptation을 잘해야한다. Modality mismatch에 대한 risk가 있을 수 있다.

Action as image

Video model이 알고 있는 것으로 action을 바꾸는것. Action head를 따로 두지 않고, 같은 generation interface 안의 visual target으로 설정하여 video representation이 disruption 되지 않도록 한다.

- GENIMA
  - Stable diffusion을 fine tuning 해서 joint action target을 generation 하도록 함.
- Cosmos policy

  ![](/images/blog/vla_to_wam/01-image.png)
- Treats action as synthetic latent video frames.
- Encodes action, proprioception, and value targets as fake frames inside the video model’s own denoising interface.

#### Latent actions and plans

- A different option is to compress behavior into latent plans or latent actions and condition the policy on those.
- This is attractive because full video prediction is expensive, and most pixels are not actually needed for control.
- Latent plans
  - multi-step window and often need paired robot data
- Latent actions
  - Genie/LAPA style can be learned from unlabeled video
- Play-LMP
  - Sub-task를 small latent space로 compression 시킨다.
  - Conditioning the low-level policy를 intermediate abstraction 시킨다.
  - Posterior network compressed short trajectory windows into a latent plan, a prior learned to predict that latent plan from the current observation and goal image.
- Genie
  - learning from unlabeld internet video and used to drive an action-conditioned world model
  - learn an action-like abstraction from video without having ground-truth robot actions
- LAPA
  - latent-action pre-training toward VLA-style robot learning
- Being-H0.7

  ![](/images/blog/vla_to_wam/02-image.png)

  - prior/posterior는 latent-plan logic으로 설정하고, executes it at foundation model
    - Mixture of Transformers backbone 사용
    - posterior branch 와 prior branch가 따로 있음 ( play-LMP 스타일 )
      - posterior branch
        - get access to future observations
        - encodes them with a frozen V-JEPA2.1 vis-encoder and perciever resampler
        - 최종저긍로 K-future embedding을 만듦
      - prior branch
        - learnable latent query + context condition 을 가지고 future-informed latent state를 만들고자 한다.
    - 실제 inference 때에는 Posterior branch가 없음.
- DreamDojo

정리하자면, Latent-method는 video로 부터 behavioral abstraction 자체를 학습하려고 하는거고, robot action abstraction을 나중에 학습하려고 하는것이다.

### 3. Architecture : Hierarchical, Monolithic, or MoT?

#### Hierarchical

- Video world prediction module 과 Action prediction module이 완벽하게 다름
- Pros
  - Flexible
- Cons
  - Video - action 이 완전히 분리되어 있어 weak coupling을 가진다.

#### Monolithic transformer

- Like DreamZero put video and action denoising in the same stack, which gives them strong coupling between two streams
- 하나의 DiT가 action, video 모두 다 생성하는 하나의 구조

#### Mixture of Transformers ( MoT)

- current default, including in modern VLA
- shared self-attention을 바탕으로 video generation, action generation을 모두 하는 구조를 말함.
- pi-0, pi-0.5 등 recent WAMs like LingBot-VA, Fast-WAM이 여기에 많이 쓰임.

## Why WAM is powerful?

1. video backbones got much stronger. DiT-based models like Wan and Cosmos replaced earlier CNN-based stacks, with better temporal compression, flow matching objectives and well curated web-scale video data
2. 이런 모델 백본이 지금은 접근이 가능하여서, post-train 같은게 가능하다.
3. 예전과 다르게 MLP로 action을 예측하는것이 아니라, transformer와 같은 flow-matching head를 활용하여 action prediction을 chunk 단위로 할 수 있게 되었다는 장점이 존재.

### But.. Practical considerations

- High training cost
  - Video backbones process many more tokens than image conditioned action policies
- Slow inference
  - Policies that generate or denoise future video latents are slower than simple VLAs
- Memory and systems complexity
  - Long video-token sequences push GPU memorys.

### VLA again?

- VLA는 이제 대부분 하나의 아키텍쳐로 귀결 : Mixture of Transformers
- VLMs are pre-trained for discrete next-token prediction with a cross-entropy loss.
- Fine-tuning vLM with flow matching objectives leads to catastrophic forgetting
